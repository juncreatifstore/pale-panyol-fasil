# Pale Panyol Fasil

Boutique officielle du livre **Pale Panyol Fasil: Español Fácil para Haitianos**, écrit par Dieudonné Almonord.

## Technologies

- Next.js 16 et TypeScript
- Supabase pour les produits, commandes, paiements et expéditions
- Mercado Pago pour les paiements
- WhatsApp Cloud API pour le conseiller automatisé
- API d’expédition pour les devis et étiquettes
- Vercel pour l’hébergement

## Développement

1. Copier `.env.example` vers `.env.local`.
2. Ajouter les variables nécessaires sans les publier dans Git.
3. Installer avec `pnpm install`.
4. Lancer avec `pnpm dev`.

Le projet se compile avec `pnpm build`.
